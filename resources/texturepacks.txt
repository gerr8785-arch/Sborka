## 6. ПРАВИЛА ИСПОЛЬЗОВАНИЯ
# 1) Порядок: RU_Lang → Aetherfall UI → Stay True → атмосфера → звук.
# 2) Один «стиль»: Stay True ИЛИ Faithful ИЛИ Bare Bones. Смешение = визуальный хаос.
# 3) Паки не должны содержать модели мобов из GeckoLib-модов (Fresh Animations это соблюдает).
# 4) После смены паков — перезапуск клиента (не только F3+T): часть кешей текстур не перечитывается.
# 5) При шейдерах: избегать паков с запечённым освещением (Patrix, Stratum) — ломают PBR.
#
