# 12. Система репутации и квестов жителей

> Ни одного мода 1.20.1, который даёт **многофракционную по-деревенскую** репутацию с открытием торговых слотов. Поэтому система собрана из: **KubeJS** (логика) + **scoreboard** (хранение) + **FTB Quests** (квесты и награды) + **Easy NPC** (диалоги) + **Numismatic Overhaul** (цены) + **Guard Villagers** (агрессия). Всё серверно-авторитетно и синхронизируется через PMMO/FTB-каналы не требуется: репутация читается по требованию.

## 12.1 Пять фракций

| Фракция (ID) | Профиль | Специализация | Деревня-дом | Цвет/иконка | Соперник |
|---|---|---|---|---|---|
| **Земледельцы** (`farmers`) | фермеры, пастухи, рыбаки | еда, семена, животные, теплицы | CTOV `village_plains`, `village_savanna` | зелёный, колос | Торговый Дом (цены) |
| **Ремесленники** (`artisans`) | кузнецы, каменщики, инженеры | снаряжение, апгрейды, сокеты | CTOV `village_taiga`, `village_snowy` | оранжевый, молот | Алхимики (материалы) |
| **Стража** (`guards`) | стражники, наёмники, ветераны | оружие, оборона, наёмники | CTOV `village_plains_fortified`, Towns and Towers | стальной, щит | — (нейтральны) |
| **Алхимики** (`alchemists`) | травники, маги, жрецы | зелья, свитки, реликвии | CTOV `village_desert`, `village_jungle` | фиолетовый, колба | Ремесленники |
| **Торговый Дом** (`traders`) | купцы, караванщики, ростовщики | монеты, редкие товары, контрабанда | хаб + города Towns and Towers | золотой, весы | Земледельцы |

**Последствия соперничества (мягкое):** выполнение квестов одной фракции даёт **+100 %** репутации ей и **+25 %** — союзнику, **−10 %** — сопернику (не «минус за всё»: игрок не наказывается за игру).

## 12.2 Шкала и статусы

| Статус | Диапазон | Что открывает |
|---|---|---|
| **Враждебно** | −500 … −151 | стража атакует, торговцы не говорят, квесты недоступны, за голову — награда |
| **Недоверие** | −150 … −1 | цены +30 %, только базовые товары, квесты «искупления» |
| **Нейтрально** | 0 … 199 | базовый ассортимент, 3 квеста, обычные цены |
| **Уважение** | 200 … 499 | +2 торговых слота, редкие товары, скидка 10 %, доступ к «мастерским» рецептам фракции |
| **Почёт** | 500 … 899 | новые квесты старейшины (сложные), наёмник фракции, скидка 20 %, +1 слот Curios |
| **Легенда** | 900+ | эксклюзивный NPC-компаньон, уникальная структура фракции, контрабандные торговцы, скидка 30 % |

**Правила:**
1. Репутация хранится **по деревне** (`rep_<villageId>_<faction>`) и **по фракции глобально** (`rep_global_<faction>`).
2. Действие в деревне даёт 100 % в локальную шкалу и 40 % в глобальную.
3. Статус для торговли/диалогов = **максимум** из (локальный, глобальный − 1 статус) — «тебя знают в лицо» важнее общей славы.
4. Затухание: −1 % в игровой день, но **не ниже нижней границы текущего статуса** (нельзя потерять Легенду из-за отпуска, но нельзя и «законсервировать» её навсегда).

### Время обновления квестов (J.3)
- Обновление пула NPC: **каждые 3 игровых дня** (`kubejs/server_scripts/rep_quests.js`, счётчик = `level.day % 3`).
- После выполнения квеста NPC выдаёт следующий **сразу**, если лимит (3 / 5 с Почётом) не исчерпан.
- «Служба (доктор)» — старейшина: конфигурируемо, `config/easynpc/quests.json`:
  - какие квесты: 3 пула (T1 / T2 / T3+) по стадии игрока;
  - порядок: сначала «сюжетный», затем случайные;
  - одновременно у старейшины: **2** (сюжет + 1 фракционный).

## 12.5 Техническая реализация

### Хранение (scoreboard, `world/scoreboard.dat`)
```
objective: rep            тип: dummy
  критерий для игрока: rep.<player>.<faction>            → глобальная
  критерий для деревни: rep_v<villageId>.<faction>       → локальная (хранится у игрока в NBT+score)
objective: rep_total      — суммарная «известность» (для сортировки в HUD)
```
Почему scoreboard, а не NBT игрока: **переживает смерть**, работает с `/scoreboard`, виден в трекере, не теряется при респавне, не бэкапится отдельно от мира.

### Команда пака (KubeJS `server_scripts/rep_commands.js`)
```
/aetherfall rep add <игрок> <фракция> <число> [village]      — начислить/снять, с пересчётом статуса
/aetherfall rep get <игрок> <фракция> [village]              — текущее значение + статус
/aetherfall rep list <игрок>                                 — таблица 5 фракций
/aetherfall rep set <игрок> <фракция> <число>                — для админов/ивентов
/aetherfall village here                                     — ID текущей деревни (по ближайшему POI)
```
Пример (реальная сигнатура KubeJS):
```js
// kubejs/server_scripts/rep_commands.js
const FACTIONS = ['farmers','artisans','guards','alchemists','traders']
const STATUS = [[900,'legend'],[500,'honor'],[200,'respect'],[0,'neutral'],[-150,'distrust'],[-9999,'hostile']]

function statusOf(v) { for (const [min, id] of STATUS) if (v >= min) return id; return 'hostile' }

ServerEvents.commandRegistry(event => {
  const { commands: Commands, arguments: Arguments } = event
  event.register(Commands.literal('aetherfall')
    .then(Commands.literal('rep')
      .then(Commands.literal('add')
        .then(Commands.argument('player', Arguments.PLAYER.create(event))
          .then(Commands.argument('faction', Arguments.STRING.create(event))
            .then(Commands.argument('amount', Arguments.INTEGER.create(event))
              .executes(ctx => {
                const player = Arguments.PLAYER.getResult(ctx, 'player')
                const faction = Arguments.STRING.getResult(ctx, 'faction')
                const amount = Arguments.INTEGER.getResult(ctx, 'amount')
                if (!FACTIONS.includes(faction)) return 0
                const sb = player.level.server.scoreboard
                const obj = sb.getOrCreateObjective('rep')
                const name = `rep.${player.username}.${faction}`
                const cur = obj.getScore(name) ?? 0
                const next = Math.max(-500, Math.min(1200, cur + amount))
                obj.set(name, next)
                const before = statusOf(cur), after = statusOf(next)
                if (before !== after) player.tell(Text.of(`§6[${faction}] ${before} → ${after}`))
                return 1
              })))))))
})
```

### Мост «квест → репутация»
FTB Quests награда-команда: `/aetherfall rep add @p farmers 40` (см. [quest-tree.md](quest-tree.md) §10.9).

### Мост «репутация → торговля»
KubeJS `TradeEvents` (один владелец цен):
```js
// kubejs/server_scripts/rep_trade.js
const DISCOUNT = { hostile: 1.6, distrust: 1.3, neutral: 1.0, respect: 0.9, honor: 0.8, legend: 0.7 }
ItemEvents.rightClicked('minecraft:emerald', e => { /* показать статус перед сделкой */ })
MoreJS.villagerTrades(e => {
  const rep = e.level.server.scoreboard.getOrCreateObjective('rep').getScore(`rep.${e.player.username}.traders`) ?? 0
  // скидка применяется множителем к цене emerald-сделки через patched offer
})
```
> ⚠ Прямой пересчёт цен через `MerchantOffer` требует патча мода — в v1.0 реализуем **скидку через «купонную» механику**: торговец выдаёт `aetherfall:coupon_<faction>_<tier>` (KubeJS-предмет), который при ПКМ на торговце делает 1 сделку бесплатной/дешёвой. Это безопасно и проверяемо. Точные цены — в `TradeEvents` KubeJS.

### Мост «репутация → агрессия стражи»
```js
// kubejs/server_scripts/rep_guards.js
PlayerEvents.tick(e => {
  if (e.level.tickCount % 40 !== 0) return
  const p = e.player
  const rep = /* guards */ 0
  const tag = 'aetherfall:hostile_to_guards'
  if (rep <= -151 && !p.tags.contains(tag)) { p.addTag(tag); p.tell(Text.of('§cСтража объявила тебя врагом!')) }
  if (rep > -151 && p.tags.contains(tag)) p.removeTag(tag)
})
```
`GuardVillagers` конфиг: `attackHostilePlayers: true`.

### Диалоги (Easy NPC)
- Каждый NPC — `config/easynpc/<villageId>/<npcId>.json`: модель, скин, профессия, фракция, 6 веток диалога (по статусу), 2–4 квеста-тега.
- Кнопка `[Работа]` → `/ftbquests open_modpack <chapter>` (глава фракции) или выдача квеста.
- Кнопка `[Купить]` → открывает торговлю (Easy NPC `enableTrading`, цены через купоны).
- Взгляд в лицо (`lookAtPlayerRange: 12`) → `[F] Говорить`.

| `village_savanna` | Земледельцы | Старейшина + Пастух | скот, шерсть, кожа |
| `village_taiga` | Ремесленники | Старейшина + Кузнец | инструменты, железо |
| `village_snowy` | Ремесленники | Старейшина + Каменщик | блоки, декор, стройматериалы |
| `village_plains_fortified` | Стража | Капитан | оружие, броня, наёмники |
| `village_desert` | Алхимики | Травник | зелья, травы, свитки |
| `village_jungle` | Алхимики | Жрец | реликвии, ритуальные компоненты |
| **Город (Towns and Towers)** | все 5 + **Торговый Дом** | Квестодатель-«Глашатай» | междеревенние квесты: ловцы, экспедиции, соревнования |

**Элитные города** (T4+): «Столица» — место междеревенних квестов:
- «Экспедиция» — совместный поход на босса (награда всем участникам);
- «Соревнование деревень» — кто больше сдаст ресурсов (таймер 3 дня);
- «Караван» — доставка груза между 3 деревнями под охраной.

**Контрабандные торговцы** (снимают гейт): появляются при **глобальной** репутации Торгового Дома ≥ Почёт, продают запрещённое (аффикс-предметы тира +1, души Goety, «Эхо Раскола») за 2× цену.

## 12.9 Чек-лист проверки системы (входит в общий чек-лист)

1. Взять квест у кузнеца → выполнить → получить награду → **репутация изменилась** (проверить `/aetherfall rep get`).
2. Довести фракцию до «Уважение» → у торговца появился новый слот / купон со скидкой.
3. Довести до «Почёт» → старейшина выдал «сложный» квест.
4. Довести до «Легенда» → появился компаньон / открылась структура.
5. Уронить до «Враждебно» → стража атакует, торговец отказывает.
6. Перейти в **другую деревню** → репутация другой (локальная шкала), глобальная — общая.
7. Смерть игрока → репутация сохранилась (scoreboard переживает смерть).
8. Перезапуск сервера → репутация сохранилась.

**Самопроверка раздела:** 5 фракций ✓ 6 статусов ✓ 13 источников изменения ✓ 4 уровня открытия ✓ локальная+глобальная шкала ✓ 12 типов NPC с квестами ✓ диалоги по статусу ✓ расчёт «взгляд в лицо → F» ✓ хранение/команды/мосты ✓ конфиги ✓ HUD ✓.
