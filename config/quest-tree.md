> Движок: **FTB Quests** (главы), выдача от NPC — через мост Easy NPC → FTB (см. [reputation-system.md](reputation-system.md)).

## 10.9 Реализация: как это живёт в FTB Quests

**Структура файлов (датапак `10_aetherfall_quests`):**
```
data/ftbquests/quests/
├── chapters/
│   ├── 00_prologue.snbt
│   ├── 01_house.snbt
│   ├── … 09_chronicles.snbt
├── chapter_groups.snbt        ← «Пролог / Становление / Средний тир / Эндгейм / Пост»
├── reward_tables/
│   ├── aetherfall_t1.snbt … aetherfall_t5.snbt
└── data.snbt                  ← настройки: hide_until_unlocked, team_sharing
```

**Пример квеста (фрагмент SNBT — готов к вставке):**
```snbt
{
  id: "1A2B000000000001"
  title: "Пепел на пороге"
  subtitle: "Старейшина ждёт ответа"
  icon: "minecraft:oak_log"
  tasks: [{
    id: "1A2B000000000002"
    type: "item"
    item: "minecraft:oak_log"
    count: 8L
  },{
    id: "1A2B000000000003"
    type: "item"
    item: "minecraft:cobblestone"
    count: 4L
  }]
  rewards: [{
    id: "1A2B000000000004"
    type: "xp"
    xp: 200
  },{
    id: "1A2B000000000005"
    type: "command"
    command: "/give @p farmersdelight:bread_slice 8"
    silent: true
  },{
    id: "1A2B000000000006"
    type: "command"
    command: "/aetherfall rep add @p traders 40"
    silent: true
  }]
  dependencies: ["1A2B000000000000"]
  min_width: 1.0d
}
```

**Динамические квесты (жизненные навыки) — KubeJS `server_scripts/dynamic_quests.js`:**
```js
// Квест «Улов дня» — обновляется каждые 3 игровых дня
PlayerEvents.tick(event => {
  const day = event.level.day
  if (day % 3 !== 0) return
  const pool = ['aquaculture:atlantic_cod','aquaculture:tuna','fishofthieves:splashtail','aquaculture:catfish']
  const pick = pool[(day/3) % pool.length]
  event.server.runCommandSilent(`ftbquests change_progress ${event.player.username} quest:2.5 set 0`)
  // и переписать задачу через FTB API недоступно — поэтому используем 4 заранее созданных квеста
  // и скрываем 3 из них: hide_until_unlocked + stage
})
```

> ⚠ Важно: FTB Quests **не позволяет менять предмет задачи из скрипта**. Поэтому «улов дня» реализован как **4 предзаготовленных квеста** с гейтом по дню (`kubejs` выдаёт stage `day_0..3`, FTB показывает нужный). Это единственный надёжный способ без патча мода.

**Награды-команды:** `/aetherfall rep add <player> <faction> <amount>` — наша KubeJS-команда (см. [reputation-system.md §12.5](reputation-system.md)).

**Самопроверка раздела:** 10 глав ✓ 73 квеста ✓ в каждой главе есть ⚔/🧺/🏗/💰 ✓ награды в XP/монетах/предметах/репутации ✓ реализация в FTB + ограничение задокументировано ✓.
