Здесь лежат конфиги сборки. Они копируются в <инстанс>/config при установке.

Готовые пресеты (их можно включать/выключать, переименовывая файлы):
  iris.properties.example        — шейдеры выключены по умолчанию (слабый ПК)
  sodium-options.json.example    — пресет «слабый ПК» для Sodium
  server.properties.example      — настройки выделенного сервера (6 чанков)
