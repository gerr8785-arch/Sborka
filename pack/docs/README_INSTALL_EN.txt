==========================================================
 "Sborka RPG" — a cozy RPG sandbox pack
 Minecraft 1.20.1 · Fabric · ~105 mods · tuned for low-end PCs
==========================================================

INSTALL (client)
  A) *.mrpack  -> Prism Launcher: Add Instance -> Modrinth -> Import from file.
     Prism installs Fabric Loader 0.20.1 and all mods automatically.
     Give the instance 3 GB of RAM (minimum 2.5 GB).
  B) folder client/ -> copy its contents over a fresh Fabric 1.20.1 instance.

INSTALL (server)
  copy server/ to the host, run: java -Xmx3G -jar fabric-server-launch.jar nogui
  (eula.txt already accepts the EULA, view-distance is already lowered to 6).

LOW-END PRESET (already applied in options.txt)
  render distance 6, simulation distance 5, fast graphics, fewer particles,
  shaders disabled, Sodium + Lithium + Krypton + C2ME + EntityCulling +
  ImmediatelyFast + More Culling. Need even more FPS? Drop render distance to 4
  and disable Falling Leaves / Visuality / Not Enough Animations in Mod Menu.

FIRST STEPS
  pick your origin and class, open the quest book (J), find a village and use
  its bounty board, place a Waystone, press R for recipes and M for the map.
